# Matcha Reader assets

Fonts and dictionaries for [Matcha Reader](https://github.com/eszter007/matcha-reader). They change much less often than the firmware, so they live here and get their own versions. Firmware updates don't need new fonts or dictionaries unless the firmware release notes say so.

Every zip unpacks to the right place: unzip it and copy what's inside to the root of the SD card.

## Fonts

Download from the [latest fonts release](https://github.com/eszter007/matcha-reader-assets/releases/tag/fonts-1.0).

| You read | Zip | Fonts |
| --- | --- | --- |
| Japanese | `japanese-fonts.zip` | Noto Sans JP, Noto Serif JP |
| Mandarin, simplified | `chinese-fonts-simplified.zip` | Noto Sans SC, Noto Serif SC |
| Mandarin, traditional | `chinese-fonts-traditional.zip` | Noto Sans TC, Noto Serif TC |
| Latin text in Noto Sans | `noto-sans-font.zip` | Noto Sans |

## Dictionaries

Download from the [latest dictionaries release](https://github.com/eszter007/matcha-reader-assets/releases/tag/dictionaries-1.0).

| Language | Zip | Ends up in |
| --- | --- | --- |
| Japanese | `japanese-dictionaries.zip` | `dictionaries/jp/` |
| Mandarin, simplified | `dictionaries-zh-simplified.zip` | `dictionaries/zh/` |
| Mandarin, traditional | `dictionaries-zh-traditional.zip` | `dictionaries/zh/` |
| Cantonese | `dictionaries-yue.zip` | `dictionaries/yue/` |

Install only one of the two Mandarin packs, since both use `dictionaries/zh/`.
